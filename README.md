# System Admin Toolkit

A Bash-based system administration toolkit for system health monitoring,
directory backups, backup rotation, and log analysis.

## Features

- System health monitoring
- Directory backup creation
- Timestamped backups
- Automatic backup rotation
- Backup listing
- Log analysis
- Log searching
- Events-per-hour timeline

## Usage

### System Health

```bash
./sysadmin-toolkit.sh health
